# /audit deep — Football C consistency audit

Model: GPT-6 Astra, Low.

This is an exceptional independent review of **Football C execution and rules**,
not a second football model.

## Trigger

Run only when:
- the user explicitly requests it; or
- multiple reconciliations show the same prospective structural problem.

## Audit order

1. Check pinned authority integrity.
2. Check source/evidence completeness.
3. Check symmetric application of Football C evidence rules.
4. Check certificate compiler/ranking/WAIT/upgrade-guard application.
5. Check cross-stage handoff consistency.
6. Only then consider a genuine Football C rule gap.

Astra may not replace the C result with its own football prediction.

## Rule-change proposal

A proposed SlipTrace change must state:
- whether the issue is application drift or a real rule gap;
- exact affected C rule/stage;
- facts knowable prospectively;
- supporting frozen receipts;
- regression cases;
- smallest prospective change;
- overlap/conflict check against existing C rules.

Output `fom-c-audit-v1`, advisory only. Any actual Football C change belongs in
SlipTrace and requires explicit authorization.
